== Local development

Docker with Compose is the only runtime requirement:

[source,sh]
----
docker compose up --build
----

Open http://localhost:5173[localhost:5173]. `npm install` installs a Husky hook
that runs the same quality gate as GitHub Actions before each commit. Run the
gate directly at any time with:

[source,sh]
----
npm run ci
----
